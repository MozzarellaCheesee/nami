## 🎧 Что такое Nami?

Nami — это музыкальный плеер и личная музыкальная экосистема вокруг **вашей собственной коллекции**.

Вместо каталога, который принадлежит сервису, Nami строится вокруг файлов, которые принадлежат вам: локальная музыка, собственная библиотека, нормальные тексты, история прослушиваний, плейлисты и статистика.

Можно начать максимально просто:

**скачать APK → выбрать свою музыку → слушать.**

А когда понадобится музыка на нескольких устройствах, подключается **Nami Server** — ваш собственный сервер для синхронизации и стриминга.

<p align="center">
  <strong>Ваша музыка → ваш плеер → ваш сервер → ваши устройства.</strong>
</p>

# 🎛 Что умеет Nami

## 🎼 Форматы

Nami рассчитан не только на MP3. В зависимости от платформы и конкретного устройства поддерживаются, среди прочего:

`FLAC` · `ALAC` · `DSD` · `DSF` · `DFF` · `WavPack` · `APE` · `TAK` · `WAV` · `AIFF` · `Musepack` · `Opus` · `AAC` · `MP3` · `Ogg Vorbis` · `MOD` · `XM` · `IT` · `S3M` · `NSF` · `SPC` · `VGM` · `CUE`

## 🎵 Плеер

Nami рассчитан не только на «нажать Play».

В приложении есть:

- FLAC, ALAC, DSD/DSF/DFF и другие аудиоформаты;
- Hi-Res playback;
- bit-perfect через USB-ЦАП там, где это поддерживает конкретное устройство;
- эквалайзер и AutoEq;
- ReplayGain / выравнивание громкости;
- crossfade, crossfeed, limiter и другие инструменты обработки;
- waveform, BPM и тональность прямо в плеере;
- управление очередью;
- скорость воспроизведения и режимы для разучивания;
- бесшовное воспроизведение;
- фоновое воспроизведение и системные media controls.

Для продвинутых сценариев аудио поведение и возможности конкретного устройства могут различаться.

---

## 🎤 Тексты и караоке

Тексты в Nami — не просто маленькая строка под обложкой.

Поддерживаются сценарии с синхронизацией строк, караоке и несколькими представлениями текста.

Для японской музыки Nami также развивает отдельный сценарий:

**японский текст → фуригана / ромадзи → перевод → чтение по строкам.**

Это особенно полезно, если вы не просто слушаете песню, а хотите разбирать её текст.

---

## 🧠 Режим «Разучить»

Музыку можно использовать не только для прослушивания.

Режимы для практики включают:

- изменение темпа без изменения высоты;
- повтор выбранного фрагмента;
- точный A–B loop;
- повторы с паузами;
- постепенное ускорение;
- собственные заметки;
- индивидуальный темп и тональность для материала.

---

## 📊 Статистика и итоги

Nami сохраняет историю прослушивания и превращает её в визуальную статистику.

В зависимости от режима использования доступны:

- минуты прослушивания;
- история;
- оценки;
- наиболее слушаемые исполнители и треки;
- распределение прослушиваний;
- месячные и годовые итоги;
- персональная «волна» рекомендаций внутри собственной библиотеки.

# 🌐 Nami Server

Если локального режима уже недостаточно, поднимается **Nami Server**.

Это ваш личный музыкальный сервер, который можно разместить дома, на NAS, VPS или другом устройстве.

```text
                     ┌───────────────┐
                     │  Nami Server  │
                     │   Your data   │
                     └───────┬───────┘
                             │
              ┌──────────────┼──────────────┐
              │              │              │
          📱 Android      💻 Windows     🐧 Linux
              │              │              │
              └──────────────┼──────────────┘
                             │
                      🎵 Your library
```

### Что даёт сервер?

- общую музыкальную библиотеку;
- стриминг на устройства;
- синхронизацию плейлистов;
- синхронизацию избранного;
- историю прослушивания;
- оценки;
- загрузку музыки на сервер;
- офлайн-загрузки на клиент;
- несколько пользователей;
- Jam — совместное прослушивание;
- ссылки для обмена;
- Discord Rich Presence;
- веб-панель;
- Docker-развёртывание.

### Установить сервер

**Linux:**

```bash
curl -fsSL https://raw.githubusercontent.com/MozzarellaCheesee/nami/main/install.sh | bash
```

**Windows PowerShell (от администратора):**

```powershell
irm https://raw.githubusercontent.com/MozzarellaCheesee/nami/main/install.ps1 | iex
```

**Docker:**

```bash
docker run -d \
  --name nami \
  --restart unless-stopped \
  -p 4533:4533 \
  -v /path/to/music:/music:ro \
  -v nami-data:/data \
  ghcr.io/mozzarellacheesee/nami-server:latest
```

После запуска откройте веб-панель сервера и подключите устройство через **Настройки → Сервер** в Nami.

> [!IMPORTANT]
> Перед публикацией сервера в интернет настройте HTTPS и продумайте модель удалённого доступа. Для домашнего использования сервер можно оставить только в локальной сети.

# 🔄 Один аккаунт — несколько устройств

Nami Server объединяет устройства в одну экосистему.

Например:

```text
        📱 Телефон
             │
             │
             ▼
     ┌───────────────┐
     │  Nami Server  │
     └───────────────┘
             ▲
             │
             │
        💻 Компьютер
```

Начали песню на телефоне — продолжили на компьютере.

Поставили оценку — она синхронизировалась.

Создали плейлист — он появился на другом устройстве.

Скачали музыку для офлайна — её можно слушать даже без доступа к серверу.

# 🔐 Приватность и контроль

Nami строится вокруг идеи **“ваша музыка остаётся вашей”**.

Локальный режим:

- не требует обязательного аккаунта;
- не требует собственного сервера;
- не требует постоянного интернета.

При использовании Nami Server:

- сервер можно держать только в домашней сети;
- библиотека хранится на выбранном вами сервере;
- внешние сетевые возможности подключаются отдельно;
- доступ к серверу контролируется пользователем.

Для удалённого доступа можно использовать собственный HTTPS reverse proxy, Tailscale или другой подходящий вам способ.

# ❓ FAQ

<details>
<summary><strong>Нужен ли Nami Server?</strong></summary>

Нет.

Для локального прослушивания достаточно установить Android или desktop-приложение и указать папки с музыкой.

Server нужен, когда хочется одной библиотеки на нескольких устройствах, удалённого доступа, синхронизации, Jam и других сетевых возможностей.
</details>

<details>
<summary><strong>Нужен ли интернет для прослушивания?</strong></summary>

Нет для базового локального сценария.

Nami рассчитан на работу с локальной коллекцией. Сетевые функции — отдельное расширение.
</details>

<details>
<summary><strong>Это стриминговый сервис?</strong></summary>

Нет в классическом смысле.

Nami не пытается заменить каталог подписочного сервиса. Он предназначен прежде всего для вашей собственной музыки.
</details>

<details>
<summary><strong>Где исходный код?</strong></summary>

Исходный код Nami находится в приватном репозитории. Этот репозиторий предназначен для публичных релизов, установки, документации и changelog.
</details>

<details>
<summary><strong>Как обновить Nami?</strong></summary>

Android-версия проверяет обновления из приложения: **Настройки → Обновления**.

Для desktop и сервера используйте актуальный релиз из GitHub Releases.
</details>
